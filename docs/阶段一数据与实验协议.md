## 3. 标签和输入约定

三个任务均为二类前景分割：MoNuSeg 为细胞核，cov19、MosMedData 为所提供感染区域掩码的前景。

原始文件不重写。背景 0，前景按原始灰度值 >0 定义。15 张 MosMedData bjorke 掩码含 0、12、17、21、255，与上传参考文件相同；不擅自改成 >=128。

数据读取合同：

1. 依照固定清单配对，不用无序目录列表拼接。
2. 初始 LViT 整图缩放至 224×224，不额外切块。
3. 图像双线性缩放；LViT 维持上传代码的三通道 BGR 及 /255 约定，灰度图复制三通道；Qwen 使用 RGB。
4. 掩码先按 >0 二值化，再最近邻缩放至 224×224。
5. 空间增强必须同步处理图像、掩码、框及相关空间文字。调试先禁用几何增强，正式增强配置在阶段二固定。

第 4 项是统一后的显式规则。历史加载器默认 resize 后再非零二值化，边界可能不同；如需逐项复刻历史处理，用另行登记的 legacy_loader_resize_v1 对照，不将不同预处理混入同一主比较表。

## 4. 文本和提示来源

Excel 包含 Image、Description，键对应实际掩码文件名。保留 cov19 的 mask_ 前缀及 MoNuSeg .tif 到 .png 配对规则。

明确区分：

- provided_legacy_text：随历史数据提供的描述。生成过程尚未独立核实，不默认视为可部署时获得的临床报告。
- qwen_predicted_text：Qwen 仅依据图像和目标生成的描述。
- qwen_predicted_grounded_evidence：Qwen 预测短描述和框。
- oracle_reference：用真实标签构造的参考提示，仅作额外监督或上界，单列。

测试掩码不进入提示生成、超参数或阈值选择、检查点选择及后处理调参。Qwen 试跑使用训练/验证样本，不根据测试集结果调整提示词。

## 5. 评价和模型选择

- 主指标：逐图前景 Dice 宏平均；同时报告逐图前景 IoU 宏平均。
- sigmoid 概率固定以 >=0.5 为前景。
- Dice = 2TP / (2TP + FP + FN)；IoU = TP / (TP + FP + FN)。
- 双方均空时两项均为 1，仅一方为空时均为 0。
- 原生 0～1 计算，最终百分数报告；平均分母使用清单实际样本数。
- 初版在 224×224 评价网格上计算；增加原分辨率评价须另行登记并对所有方法一致使用。
- 以验证集宏平均 Dice 选择检查点；并列时保留更早检查点。
- 测试集仅用于设置冻结后的最终评价。
- 记录 Qwen、文本处理、分割及总耗时；GPU 计时进行 CUDA 同步。

优化器、训练预算、早停及正式增强属于阶段二，在正式比较前固定。当前阶段不声称复刻了原论文全部训练细节。

## 6. 已知划分限制

本协议为用户指定的历史复现协议，不宣称三个数据集都满足患者独立划分。

cov19：训练和验证有 sub-S10477、sub-S10636 两个可识别患者 ID 交叉；部分 covid_ 文件名无法恢复患者 ID。没有跨划分重复图像，也不能证明患者完全独立。

MosMedData 的文件名病例/序列归组交叉：

- 训练—验证：Jun_coronacases_case8、bjorke。
- 训练—测试：Jun_coronacases_case8、Jun_radiopaedia_40_86625_0_case18、bjorke。
- 验证—测试：Jun_coronacases_case8、Morozov_study_0299、bjorke。

case8 的训练/验证/测试切片数为 2/2/135，仍需来源元数据确认患者关系；当前结果不直接表述为患者独立泛化。

MoNuSeg：本轮未发现跨划分同名、相同像素或可识别 TCGA 患者 ID 重叠，因此作为首个完整任务。

未来若建立严格患者独立协议，应另建清单，让全部方法在同一新协议下重跑，保留本协议不覆盖。
