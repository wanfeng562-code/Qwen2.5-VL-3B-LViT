# 阶段4.6运行与验收

云端项目：`/root/autodl-tmp/Qwen2.5-VL-3B-LViT`。所有命令在该目录执行，沿用base环境。

## 当前流程

现有训练控制器按预定顺序完成匹配对照。独立验收控制器等待它退出，不创建新的训练任务、不重启失败任务，也不扩展14次新训练上限。

训练结束后依次执行：开发审查 → 四组各三种子验证预测与72份PNG重算 → 同时驻留单图测速。三种子验证门槛通过才进入验证图特征重放、最终冻结、测试特征提取、12个检查点统一复测、210份新旧PNG独立重算和报告。验证门槛失败时直接报告验证结果，保持测试关闭。

这里的最终测试称“原划分上的最终复测”，不能称盲测。脚本全部通过不自动等于达到提升目标；还须查看六项数值门槛、全部种子和逐图误差，并由主代理打开图表核验。

## 查看真实进程与日志

```bash
cat outputs/phase46/confirmation/status.json
cat outputs/phase46/finalization/status.json
cat outputs/phase46/confirmation/process.json
cat outputs/phase46/finalization/process.json
```

用process.json中的实际PID执行`ps -p PID -o pid,stat,etime,args`。状态文件只是记录，不能替代进程存活证据。日志位于`outputs/phase46/runs/各运行名/run.log`与`outputs/phase46/finalization/各阶段脚本名.log`。

如果验收状态为failed，先读取error和对应日志。不得因为观察超时或旧状态文件就重新启动训练；同一训练的断点恢复保留原配置、运行ID和预算名额。

## 主要产物

- `outputs/phase46/registry.json`：正式训练预算及状态。
- `outputs/phase46/confirmation/summary.json`：三种子验证结果及进入测试的门槛。
- `outputs/phase46/development_audit.json`：历史、早停、初始化、旧代码和新核心指纹核验。
- `outputs/phase46/visual_review/`：72份验证预测、独立指标和图表。
- `outputs/phase46/benchmark.json`：第一张验证图的batch1测速。完整Qwen和LViT驻留，实际仅运行视觉塔和分割网络；训练文本均值预载。
- `outputs/phase46/test_authorization.json`：仅验证门槛通过后创建，锁定12个检查点、缓存、协议和评价脚本。
- `outputs/phase46/final_test/`：若获准，保存原划分复测结果、逐图预测、独立审查与误检/漏检图。
- `docs/阶段4.6实验结果.md`：终态报告；尚未生成时不把进展快照当作最终结论。

## 冻结与复现边界

`docs/phase46_start.json`记录旧145份文件的hash，`docs/phase46_core_freeze.json`记录本轮五份训练核心文件的hash。不得修改这些源码，包括已冻结的CRLF换行。新验收脚本不改变训练身份。

固定输入仅使用24张训练图的均值；打乱输入只在各划分内错位。候选是Qwen视觉预训练特征迁移，不声称语言推理贡献；Qwen较高输入分辨率和额外资源需要一并报告。

本轮未启动LoRA、蒸馏、更多层搜索或新的超参数网格。没有测试改进证据时，不将“流程成功运行”描述为Qwen已有效提高Dice。
