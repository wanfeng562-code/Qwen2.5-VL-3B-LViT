# 阶段二至四：执行范围与验收依据

日期：2026-11-01。对应根目录《项目任务路线与实验计划.md》；阶段一固定协议 `legacy_subset_v1` 不变。

## 范围及分工

任务书明确先完成一个二维数据集的可比较实验。本轮首个训练主任务是 MoNuSeg（24/6/14），不将 cov19、MosMedData 的小规模描述试点误称为完整训练复现。后两任务的完整训练按既定顺序在扩展阶段开展。

- 主代理：实验协议、环境与模型准备、Qwen生成、GPU任务协调、集成、最终证据审查。
- GPT-6.1 Sol（xhigh）：现代 LViT 训练包装、冻结 BERT 特征、数据与恢复验证、配置和适配说明。保留 `src/lvit` 来源快照。
- GPT-6.1 Terra（xhigh）：真实图像及输出视觉检查、试点选样、独立定位评价、可视化及失败案例。不得修改训练实现或环境。

三方共用同一云端项目；GPU任务由主代理串行安排。原始外部数据目录不改动；权重、数据、特征、逐样本输出和检查点受 `.gitignore` 保护。

## 阶段二

1. 在已有 base 环境保留 Torch 2.5.1+cu124、Transformers 4.51.3，新增明确依赖并完成 `pip check`。
2. 保留原 LViT 网络，使用冻结清单、BGR/255 图像和先二值化再最近邻缩放的掩码。
3. 用冻结 `bert-base-uncased` 替换旧 MXNet `bert-embedding`；逐项披露分词、WordPiece 合并、25位置截断、10词输出、补齐与权重差异。两组实验共用相同编码器。
4. 验证真实 DataLoader、损失与原代码数值/梯度一致、单批次参数更新、小样本学习和保存恢复后下一步结果一致。
5. MoNuSeg 从头训练，三个配对随机种子 666/667/668；Adam lr=0.001、batch=2、FP32、确定性计算、无几何增强。余弦热重启 T0=10、Tmult=1、最低lr=0.0001，最多2000 epochs，至少50 epochs，验证 Dice 连续50 epochs不提高则停止。训练前冻结配置，不根据测试分数调整。
6. 验证集最高逐图宏平均 Dice 选 best（相等保留较早）；最终独立评价14张测试图。记录实际 epochs、耗时、吞吐与显存。

本轮属于统一协议下适配复现，不宣称数值等价复刻原论文。历史文本来源尚未独立证实，不能默认是部署时可得的临床报告。

## 阶段三

试点60张：MoNuSeg全30张训练/验证图，cov19和MosMedData各15张（12训练+3验证）。后两数据集按前景比例、连通域数量、亮度与清晰度覆盖选样，属于有目的试点，不能将均值当作随机总体估计。

生成器只读取图像字段；选样统计和GT独立留在审查目录。生成普通描述及最多3个粗空间区域。v1曾要求模型生成0..1000坐标，实际发现不适合Qwen2.5-VL原生坐标训练；该失败结果完整保留。v2按模型实际缩放后的像素尺寸生成绝对xyxy框，代码依据明确记录的输入宽高转换为下游0..1000坐标。密集细胞核任务不把连通域数当成细胞实例数。

验收包括：严格原始JSON有效率；仅完整围栏剥离诊断率；根据 `configs/qwen_output_contract_v1.json` 明确允许围栏剥离及顶层数组封装的适配有效率；原尺寸和224尺度的框并集覆盖/精度/IoU、域触碰及漏检、巨大框与重复/占位描述、普通文本的可见错误和无法确认细节。保留失败输出，不静默修坐标、填内容或将格式修复当作医学准确。评价与可视化的224掩码使用训练一致的OpenCV INTER_NEAREST；修正前PIL版本报告另留审计副本。

只允许依据训练/验证试点做有版本记录的提示修订；最终提示冻结后才生成测试描述。明确普通描述是否可冻结进入对照试验，定位是否需要医学适配后再进入阶段五。LoRA为条件分支，当前不以完成空间融合为阶段二至四验收项。

## 阶段四

对 MoNuSeg 的44张训练/验证/测试图生成最终版本描述，缓存相同BERT文本特征。与阶段二的已有文本对照共用数据、网络、初始种子、编码器、预算、停止规则及评价。

必须获得三次配对实验实际结果，报告 Dice/IoU 均值与样本标准差、每种子差值、生成成本/缓存体积/训练成本，不预设Qwen一定改善结果。提供新图像经 Qwen→BERT→LViT 的串联推理入口并实际验证。视觉检查包括原图、GT、两组预测及典型失败。
