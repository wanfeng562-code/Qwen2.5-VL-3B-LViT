## 评价规则

原始 `structured_raw` 必须是严格 JSON 对象，含 `regions` 数组，每项包含唯一 ID、非空 description、合法 `box`；最多 3 个框。空数组按合法无框记录，不作为定位成功。v1 使用提示要求的 0–1000 `xyxy`；v2 按生成记录中的实际缩放输入宽高，将绝对像素 `xyxy` 独立转换为归一化坐标。两者均要求有序、有限且在各自范围内，不裁剪不修正。像素映射的左上角向下取整、右下角向上取整，按半开区间栅格化，分别在原图与 224×224 计算。标签先按原值大于零二值化，再在 224 尺度以最近邻缩放。

缩放实现校正：评价最初使用 Pillow 最近邻，而训练代码使用 OpenCV `INTER_NEAREST`，两者采样坐标不同。现已统一使用与 `src.experiment.data.load_mask` 相同的 OpenCV 灰度读取、阈值化和缩放；真实 MoNuSeg 样本 `4ebfa45624cbfcabbc37` 的评价器、对照图与训练加载各相差 0 像素，原 Pillow 结果相差 6049/50176 像素，见 `outputs/visual_review/opencv_resize_alignment.json`。v1 与 v2 六例校准的 224 指标均已重算，原图汇总指标逐项保持一致；修正前 JSON 快照保存在相应 `*_before_opencv_resize_fix` 目录。此修改是实现一致性修正，不是模型或提示调参。

Qwen2.5-VL 的坐标约定在 v1 运行中被重新核对：上游文档使用输入图像对应的绝对像素坐标，而非直接假定输出 0–1000。v1 的不合适接口假设完整保留，不用 GT 对其作事后修正；v1 的坐标失败不能直接归因于医学识别能力。v2 要求输出缩放后输入图对应的像素坐标，记录宽、高和原始坐标，评价器使用记录宽高独立转换。合成 800×400 非方图的换算和越界测试已通过，真实模型是否遵循指令仍待校准。依据：[Qwen2.5-VL 官方介绍](https://qwenlm.github.io/blog/qwen2.5-vl/)。

报告格式有效率（全样本分母），并在有效输出上报告 GT 像素被预测框并集覆盖的比例、框并集内 GT 占比、并集与 GT 的 IoU、至少被一框触碰的 8 邻域 GT 连通域比例、触碰任何 GT 的预测框比例。每项标记定义分母，空掩码及空框单列。任一框覆盖至少半幅图像计为巨大框，以防整图框通过高覆盖率掩盖低精度。连通域触碰仅需一个像素重叠，是宽松的筛查；连通域不是实例标注，MoNuSeg 尤其不能解释为细胞核实例检出率。三个粗区域的提示上限也不能表达密集目标的逐核定位。

`scripts/evaluate_qwen_pilot.py` 独立重解析原始输出；已用合成情况测试非方图像的坐标端点、越界、空面积、覆盖率、两连通域触碰与整图大框。主表严格统计原始 JSON 解析和格式有效率；另设围栏恢复诊断组，仅允许移除完整且唯一的外层 `json` Markdown 围栏，绝不修复坐标或补充描述。恢复组的定位指标不能混入严格主表。额外统计与固定占位语 `short visible evidence` 完全一致的描述、同一图重复描述，以及普通描述超过 35 英文词的情况。指标不是医疗能力验证。

首轮早期检查（仅截至当时的 11 张 MoNuSeg 训练图，并非完整试点）：严格 JSON 0/11；移除完整围栏后结构有效 11/11；23 个区域描述均为提示中的占位语，10/11 张普通描述超过 35 词。恢复组原图平均覆盖 0.738、框区域精度 0.236、IoU 0.201，单框面积达半幅的 7/11。该诊断说明格式恢复不能解决内容照抄或大框问题，不能作为 60 张结论。已经打开首例 `outputs/visual_review/pilot_early_diagnostic/cases/0a0bef10f500dc48430b.png`，核验框位置与 GT 叠图；普通描述中的核密集大体可见，核仁细节无法从当前图像确认。

### v2 六例校准与固定封装合同

六例原始结构均含完整代码围栏，围栏内是区域数组而非 `regions` 对象：严格原始 JSON 0/6，单独去围栏后满足结构的仍为 0/6。经固定合同 `configs/qwen_output_contract_v1.json` 独立回放，仅移除完整围栏并将顶层数组包装为 `regions` 后有效 6/6；校准记录早于合同创建，均不带合同哈希，属于事后独立回放。任何越界、缺字段、多字段和无效区域仍判失败，不裁剪、不填充描述。完整三层结果为 `outputs/visual_review/calibration_v2_contract_diagnostic/summary.json`。13 条区域无原示例占位语，3/6 图存在重复描述，普通描述 6/6 不超过 12 词。

合同回放诊断的逐图平均覆盖 0.840、框内精度 0.127、IoU 0.112；3/6 张的框并集超过半图。高覆盖不能单独证明紧密定位。六张输入、文本、框和 GT 均已逐张打开；`outputs/visual_review/calibration_v2_array_exploratory/` 为最早明确标识的数组包装探索图。MoNuSeg/train 的单框占图 90.5%；cov19/val 的两框并集占图 62.9%，覆盖 GT 100% 但框内精度 1.9%；MosMed/train 圈选双肺，GT 很小，框内精度 0.9%。cov19 两例描述分别称上、下右肺，但框并排且高度范围大致相同；MosMed/val 的区域描述重复，且框覆盖肺外区域。上述只是六例调试观察，并非完整试点总体结论。

校准后已固定提示和封装合同，完整 60 张的 raw strict、fence-only、adapter 有效率及定位指标分别报告；不能将封装恢复宣称为原始结构合格，也不能仅凭封装问题判断医学适配是否必要。普通短描述可进入预定分割对照，其效果仍由匹配的分割实验验证。

## 分割结果可视化计划

在模型结果就绪并且确认具有同一划分、样本、训练预算和评价流程后，按 baseline 的 224 尺度逐图 Dice 升序选择最差、下中位和最佳各一例，分数相同按 sample_id 排序；选定的相同样本显示双方 Dice，并保留完整排序。该规则不是按 Qwen 提升大小挑图，也不保证代表总体；如选样来自测试集，仅在方案和阈值固定后作为最终分析，不反馈修改模型或提示。使用 `scripts/render_experiment_review.py --select-comparison` 逐例并列原图、绿色 GT、洋红 baseline 和洋红 Qwen 普通描述模型预测；两组分割预测必须为 224×224 二值掩码并标明组名。合成数据已验证排序及 Dice 算法。若没有可比模型预测，不虚构对照图。
